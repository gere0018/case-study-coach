# Case Study Coach

A guided interview that helps early-career product designers write an honest case study. Static site, no build step. Built on the [Moonglade design system](https://github.com/gere0018/moonglade-design-system); `src/tokens.css` is copied from it, do not hand-edit.

- Run locally: `python3 -m http.server`, then open http://localhost:8000
- Outside Claude it runs in basic mode (rule-based checks, nothing leaves the browser). Inside Claude it uses the `sample` capability for AI coaching.
- Original prototype: `legacy/case-study-coach.html`. Product notes: `case-study-coach-handoff.md`.
